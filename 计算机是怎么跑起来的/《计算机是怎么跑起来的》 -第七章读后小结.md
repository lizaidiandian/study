
这章讲的是 面向对象编程

面向对象编程是一种关注点在于对象(object)本身的编程方法，其背后的思想是，对象的构成要素包含对象的行为及操作。这种编程方法不仅使程序易于复用，还提升了软件的生产效率。面向对象编程所使用的编程技巧主要有继承、封装、多态这3种

面向对象的根本价值在于:可复用、可扩展、可维护
- 传统写法:一条条命令
	做完a的 -> 做b的 -> 做完b的 ->做c的
- 面对对象:一个个角色
	汽车、学生、订单、玩家

首先是 类
```c
//没有使用类的时候
int a
int b
int c
...//此处省略10000个

void fna(){ 处理过程 }
void fnb(){ 处理过程 }
void fnc(){ 处理过程 }
...//此处也省略10000个
```

可以看到,如果你要去开发或者维护这个程序,这是非常耗费心神的,不说里面的具体逻辑,就你光翻到对应的地方都累

由此,面向对象中的类由此诞生,它可以把程序中相关的函数和变量汇集到一起形成 组件
```c
class Mya
{
int a
void fna() {处理过程}
}

class Myb
{
int b
void fnb() {处理过程}
}
...
```

还没有感觉出来什么?你可以把上面代码想象成一个超大类,下面代码就是超大类中,分出许许多多的小类,小类中只包含于自己相关的内容

接下来是 对象

相信对对象都不陌生,就是真实实例

```c
//这是类
class dog 
{
	int name
	void fnDog(){
		"跑","叫"
	}
}

int dog = new dog
dog.name
dog.fnDog()
```


面向对象编程通过在对象间传递消息驱动程序

我们来看使用
- 非面向对象编程编写的程序
```c
/* 获取玩家A的手势 */ 
a = GetHand(); 
/* 获取玩家B的手势 */ 
b = GetHand(); 
/* 判定胜负 */ 
winner = GetWinner(a, b);
```
- 使用面向对象编程语言编写的程序
```c
// 获取玩家A的手势 
a = PlayerA.GetHand(); 
//获取玩家B的手势 
b = PlayerB.GetHand(); 
// 由裁判判定胜负 
winner = Judge.GetWinner(a, b);
```

他两的区别在于
- 一个的 GetHand() 和 GetWinner() 为独立存在的函数
- 另一个 GetHand() 和 GetWinner() 为隶属于对象的函数

所以,使用 c++ 这些面向对象编程语言,可以通过调用隶属于对象的函数来驱动程序,这中函数调用方式就是对象之间的"消息传递"

接下来是 封装 继承 多态

1. 封装:把数据和操作它的函数打包成“类”
	就像洗衣机的盖子,你只需要按按钮,就可以洗衣服,你不需要管里面的滚筒怎么转
2. 继承:允许新类在现有类的基础上扩展。
	猫狗都会叫会跑,那可以有个共同父类,动物类,然后去继承动物类里面方法和属性
3. 多态:不同对象对同一消息可以有不同响应。
	动物类都有叫的方法.但具体叫声由对象决定,比如狗是旺旺,猫是喵喵

那么类和对象有什么区别

类是对象的定义,而对象是类的实例
![[计算机是怎么跑起来的/内存和硬盘是怎么配合工作的？/1.png]]
我们定义好一个类,还无法直接使用类中的成员,必须先在生成该类的实例,这个实例就是对象
```c++
MyClass obj;　　　　// 创建对象 
obj.Variable = 123; // 使用对象所持有的变量 
obj.Function();　　 // 使用对象所持有的函数
```
