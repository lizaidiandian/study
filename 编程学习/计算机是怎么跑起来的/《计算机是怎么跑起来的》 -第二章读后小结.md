# 《计算机是怎么跑起来的》第二章读后小结

## 计算机模型所需的元件

计算机模型所需的元件包括**CPU、内存、I/O和时钟发生器**

## 一台机器如果想真正工作

一台机器如果想真正工作,至少要解决四个最基本问题

1. 谁来算?
2. 算的时候把数据放哪?
3. 怎么交换信息
4. 怎么步调一致,不乱套

## 对应

### 1. **CPU**:负责 解释 和 执行 程序

比如算 1 + 1,真正负责执行的就是CPU,但他并不是自己思考出来的,而是按照规则的执行者

### 2. **内存**:负责存储构成程序的指令和数据

因为工作流程是这样的 硬盘 -> 内存 -> CPU(读) ,可能会有疑惑,为什么不直接
CPU -> 硬盘 呢?因为**读取速度**
**CPU** 执行一条指令大约需要 **0.3 ~ 1 纳秒**（1 纳秒 = 十亿分之一秒）。
**内存** 读取一次数据大约需要 **10 ~ 100 纳秒**。
**硬盘**（即使是高速 SSD）读取一次数据大约需要 **几十微秒**（1 微秒 = 千分之一毫秒 = 1000 纳秒）。机械硬盘更慢，要几毫秒。

### 3. **I/O**:Input/Output（输入／输出）的缩写，负责连接计算机主机和外部设备

输入:键盘、鼠标、麦克风、摄像头等等
输出:显示器、音响、打印机等等

### 4. **时钟发生器**:时钟发生器中带有晶体振荡器，其能够产生特定频率（振动次数）的时钟信号

像音乐团队前面的指挥官,告诉你下一步做什么,做完之后下一步再说什么,避免乱套,如果没有这个统一步调,可以会出现

- CPU 可能还没算完
- 内存 还没读取到
- I/O 可能还没传完数据

时钟信号的频率可以衡量CPU的运转速度,例如，3 GHz的时钟信号就相当于每秒发出30亿次嘀嗒声

## 存储单元

接下来是 存储单元,各个元件之中都有存储单元

- CPU在解释、执行程序以及处理数据时会用到其内部的存储单元。
- 内存中的存储单元用于存储构成程序的指令和数据。
- I/O中的存储单元则用于存储在计算机主机与键盘、显示器等外部设备之间传输的数据。

**比特** 是衡量存储容量的单位,1比特能够存储1个二进制数

**CPU**内部的存储单元称为“寄存器”，`GR0～GR7`这8个寄存器是可参与所有运算的通用寄存器,存储容量为16比特,对应数值范围是`0000000000000000～1111111111111111`

内存中存储单元的容量为16比特，每个存储单元都有一个唯一的编号，这个编号叫作“地址”

![[Pasted image 20260514112753.png]]

**I/O**中存储单元的容量也是16比特,和内存一样用地址区分,地址范围为`0～3`

![[Pasted image 20260514112715.png]]

在电路中,每根导线都可以传输1比特的二进制数,低电压时传输0,高电压时传输1,16比特就需要16根导线来进行传输

导线交叉处的黑点表明导线于此处相连，如果只是交叉但没有黑点则表明不相连

## 电路连接

### 连接电源电路

我们要为**CPU**、**内存**、**I/O**和**时钟发生器**接通电源,把 `+5V`连接到每个元件的`Vcc`引脚上,再把`0V`电源连接到`GND`引脚上
- Vcc:一般表示电路的正电源电压,当 Vcc = 5V 时,表示 要接到 5伏的电源正端 才能正常工作,相当于逻辑 1
- GND:0V 基准点，也是电流返回路径, 相当于逻辑 0 

![[Pasted image 20260514114303.png]]

### 连接数据总线

这里可以理解为:

先以**CPU**为中心，把`D0～D15`这16个数据引脚分别和**内存**、**I/O**的对应引脚连接起来。这样一来，**CPU**和**内存**之间可以传输16比特的数据，**CPU**和**I/O**之间也同样可以传输16比特的数据。

![[Pasted image 20260514135426.png]]

### 连接地址总线

为什么要连接地址总线,因为内存中有 65536 个存储单元,而I/O 里面只有4个存储单元,不指明存储单元的地址,那么CPU就不知道要与哪个存储单元传输数据

![[Pasted image 20260514140653.png]]

![[Pasted image 20260514140703.png]]

### 连接控制总线

数据总线和地址总线都连接好了,但还是不能用,因为cpu分不清是谁在进行操作,那么这时候有用到四个引脚,分别为

- `MREQ`(Memory Request):表示操作对象是内存
- `IORQ`(I/O Request):表示操作对象是内存
- `RD`(Read)表示读取数据
- `WR`(Write)表示写入数据

这里的重点是:

`MREQ`、`IORQ`、`RD`和`WR`上方的横线表示它们采用的是“负逻辑”。也就是说，这些引脚平时保持高电压，只有在需要传递控制信号时，电压才会降到`0V`。

![[Pasted image 20260514141721.png]]

### 连接剩余的电路

`CLK`:时钟信号 给CPU 提供统一节拍,让他安节奏执行指令

`RESET`:重置信号 让他重新从头开始执行程序

这里主要是在补齐最后两类信号:

时钟发生器的`CLK`引脚要连接到**CPU**的`CLK`引脚上，用来提供统一节拍。`RESET`引脚采用负逻辑，平时保持高电压，当电压降到`0V`时，**CPU**会被重置，并重新从`0`号地址开始执行程序。
