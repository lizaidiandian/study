
首先,学习内存与磁盘之间的关系,要知道一个前提

**程序要先存储在存储器中，然后才被依次读取执行**

那么这种方式为 存储程序方式

存储器包括内存和磁盘

那么为什么要分出这两个出来?

有个矛盾: 
1. "快"的存储:造价贵
2. "慢"的存储:造价便宜

这个矛盾到现在也没有彻底解决,只是被巧妙的分开了,分成了 内存 和 硬盘

存储在磁盘中的程序需要先加载到内存才能运行，不能在磁盘上直接运行

![[编程学习/计算机是怎么跑起来的/内存和硬盘是怎么配合工作的？/1.png]]
举个例子:
- CPU:厨师的双手
- 内存:旁边的操作台,负责切菜,炒菜
- 磁盘:地下室,储存大量食品和餐具

可以看出CPU永远只和内存直接打交道,而磁盘上的东西,要先搬运到 内存,才能被处理

对比一下他两之间的优缺点
- 内存:速度快,容量小,断电后数据消失,贵
- 硬盘:速度慢,容量大,断电后数据保存,便宜

它两的第一个联系就是 磁盘缓存

磁盘缓存:是一块内存空间,用于临时存放从磁盘读取的数据,下次需要读取相同数据时,就不需要实际访问磁盘了,可以提高磁盘数据的访问速度

![[编程学习/计算机是怎么跑起来的/内存和硬盘是怎么配合工作的？/2.png]]


它的应用场景:浏览器通过网络从远程Web服务器上获取数据并显示,每次都请求相同的图片数据的话,会很浪费时间,但存储到磁盘缓存中,这个问题就解决了

虚拟内存

先思考一个场景,假如你的内存剩余空间 50MB,但你能打开运行 100MB 的程序,这是为什么?

虚拟内存来了,他把 磁盘空间 看做是  虚拟的内存空间 来使用,但**程序是必须运行在内存里的**,那么就诞生了一种思路,**交换**


![[编程学习/计算机是怎么跑起来的/内存和硬盘是怎么配合工作的？/3.png]]

图中可以看出,虚拟内存中存储多个页面,当真正执行 页面3的时候
- 把页面4换下来
- 把页面3换上去

那当开的程序过多时,为什么页面会卡死
1. 首先我们知道,CPU只和内存打交道,那虚拟内存不是内存,它是操作系统制造的地址空间
2. 内存爆满了,CPU发出请求地址,内存中没有这个地址,触发 **缺页中断**,**OS** 去硬盘中把数据搬回到内存中
3. 虚拟内存,本质还是磁盘,那磁盘的读取速度不是一般的慢,CPU只能慢慢等,等到 数据搬进内存之后,CPU才能读

还有一种极端情况 **抖动**

大概意思就是:系统大部分时间都在"搬家",真正干活的时间几乎为零
```text
内存满了 -> A搬到硬盘,给B搬到内存 -> B 进来之后,又需要A ->给 B 搬回去,给 A 搬回来 -> 又需要 B ....
```
缺页中断 和 OS

缺页中断:简单来说,就是内存中的地址里面没有CPU要请求的地址,就会触发,然后调用OS去硬盘了搬

OS:操作系统，负责响应缺页中断，把页面从硬盘搬到内存

了解OS之后,我们先看知道一个难题:页面置换算法

假设:内存中包含 abcd四个程序,现在又来个e程序,必须要去掉一个才能容下 e程序,换掉谁?
```java
//换成代码大概意思就是这样
int arr[4] = {a,b,c,d}
arr.push(e)
```

1.理想算法 OPT:赶走"未来最长时间内不会被用到"的那个
```text
未来访问顺序：E → B → A → C → E → D

D 最晚被用,换掉他
```
但这不可能实现,你怎么可能知道 未来 CPU会访问哪些地址

2.FIFO(先进先出):谁在内存里住得最久，赶走谁
```text
E → A -> B → A → C → E → D

a去掉 -> e去掉 -> a去掉 -> 
```
这显然不合理,一个经常使用的程序,怎么能够先去除?

3.LRU（最近最少使用）:谁用的最久没被使用,换掉谁
```text
 A -> 很久之前用过
 B -> 刚才用过
 C -> 昨天用过
 D -> 几小时之前用过
 
 去掉 A
```
那如何知道 A 很久之前用过?这就是LRU的代价
- 每次内存被访问,都要记录时间戳
- 每次置换,都要找到时间戳最小的

咋一看没有问题,但是内存访问频率,几乎每秒数亿次,这是一个不小的开销,所以,先推出了一个LRU的近似版本

4.时钟算法（Clock Algorithm）用一个循环队列和一个访问位来近似模拟 LRU 的效果，但开销极小。

再看到LRU,有些东西,他使用次数不多,但在特殊场景他必须存在,比如 雨伞,平时不用,下雨天就用上了

解决办法就是:引入强制豁免机制

核心概念:永远不参与置换,无论多久没用


补个知识点,为什么内存断电信息丢失,而硬盘不会?

内存(RAM):用电容存储数据。每一比特,由一个电容来存储,由晶体管来控制读写
- 有电荷 = 1
- 无电荷 = 0 

那么问题来了,电容会漏电

所以正常供电的时候, 约 64毫秒 给所有电容重新充电,那断电了,电容没电了,所有数据自然而然就丢失了

就像:漏水的桶,你必须一直装水,才能保持水位

硬盘(HDD):用磁场存储数据。每一个比特，对应一个极小的磁性区域（磁畴）```
```text
N S N N S S N S N N S S
↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑
每个箭头 = 一个磁畴的方向
```
特点:磁珠一旦磁化定向,不需要任何能量来维持这个方向

就像:指南针 不需要电,就能一直指向北方
