# Excalidraw Data

## Text Elements
What        Cookie 是浏览器按规则存储、自动随请求携带的数据；Session 是服务端保存的会话状态

Why         让服务端在独立 HTTP 请求之间找回“这个请求属于哪个已登录用户”

Who         浏览器持有 Session ID；服务端或共享会话存储持有 Session ID -> 用户/会话状态 映射

When        登录成功时创建；每次受保护请求时查询；登出、过期、风险事件时销毁

Where       Session ID 通常在 Cookie；用户身份、过期时间、权限快照等在服务端内存、Redis 或数据库

How         浏览器回传 Session ID，服务端用它查找 Session，再恢复用户身份

How much    服务端需要保存和查询状态，但撤销登录非常直接 ^yOpEVVno
