## Text Elements
What        Access Token 是短期访问资源的凭据；Refresh Token 是较长期的续期凭据，只用于向认证服务换取新的 Access
               Token。
  
Why         短期 Access Token 缩小泄露后的可利用窗口；Refresh Token 避免用户因 Access Token 频繁过期而反复输入密码。

Who         认证服务签发、刷新和撤销两类 Token；资源服务只接受 Access Token；客户端持有两者；用户受其泄露与失效策略
               影响。

When        登录时同时签发；业务请求时提交 Access Token；Access Token 过期时，客户端用 Refresh Token 请求认证服务续
               期；登出、异常或检测到复用时撤销。

Where       Access Token 随资源请求发送；Refresh Token 仅发送到认证服务的刷新端点。其有效性、轮换记录或撤销状态通常
              由认证服务保存。

How         认证服务验证 Refresh Token 后签发新 Access Token；更安全的做法是同时轮换 Refresh Token，并使旧 Refresh
              Token 立即失效。

How much    用户体验更平滑，泄露短期 Token 的损失更小；但系统多了刷新、轮换、撤销和并发请求处理的复杂度，长期
               Refresh Token 泄露的风险仍很高 ^KIrwkWRh
